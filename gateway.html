CENTRO DE CONEXIONES

Conecta tus aplicaciones.

Gateway es la puerta de entrada de LINK: conecta canales y servicios para que Sales OS, Payments y otros módulos puedan trabajar con ellos.

🤖 Telegram

Conecta un bot de Telegram al Gateway. El siguiente paso es introducir el token de BotFather y registrar el webhook seguro.

💬 WhatsApp

Preparado como próximo adaptador del protocolo LINK Gateway.

🌐 Web

Usa el Gateway para recibir formularios, eventos y conversaciones desde tus sitios LINK.

🔗 API

Conecta cualquier aplicación que pueda enviar eventos HTTP al protocolo LINK.

MANUAL EN 3 PASOS

Tan fácil como enchufar algo.

  1. Elige la aplicación.
  2. Introduce solamente la información que LINK te pida.
  3. Pulsa Conectar y comprueba el estado.
Estado del Gateway: interfaz instalada · protocolo y adaptadores se conectarán progresivamente sin alterar Sales OS.
